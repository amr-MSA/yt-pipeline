Privacy Policy

Last updated: October 25, 2026

This application is a personal YouTube automation tool operated by its owner.

Information Accessed

The application uses the YouTube Data API to perform YouTube-related actions authorized by the account owner. Depending on the permissions granted, this may include accessing channel information and uploading videos.

The owner sends video links to a private Telegram bot operated by the owner. The application reads these messages, downloads the linked videos using yt-dlp, and uploads them to the owner's YouTube channel. Optional cookies provided by the owner may be used to access source videos that require a logged-in session.

Use of Information

Information accessed through Google APIs is used solely to provide the application's intended YouTube automation functionality.

Storage and Sharing

The application is intended for personal use. Information accessed through the application is not sold or shared with third parties for advertising purposes. Data is shared only with the services needed to run the application: Telegram (to receive the owner's messages) and Google/YouTube (to upload videos).

The application runs on GitHub Actions. Its processing state, such as the message inbox, upload log, and confirmations, is stored in the repository's state folder.

Authentication credentials and tokens should be stored securely and should not be shared publicly.

Data Retention and Deletion

The application owner can revoke the application's access through their Google Account security settings. Locally stored credentials and application data can be deleted by the owner.

Contact

For privacy-related questions, contact the application owner through the repository hosting this policy.
