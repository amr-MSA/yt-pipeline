# مجلد الأصول (assets)

ضع هنا ملف القالب الخاص بالشورتس باسم **`template.png`** بالضبط.

- يجب أن يكون القالب بنفس منطق المشروع الأصلي: صورة عمودية تحتوي على "فتحة" (منطقة شفافة أو مخصصة)
  يُلصق فيها المقطع المُقتَص.
- الإحداثيات الحالية في `scripts/shorts_pipeline.py` (المتغيرات `TEMPLATE_NATIVE_W/H`،
  `TEMPLATE_BOX_X/Y`، `TEMPLATE_BOX_W/H`) مأخوذة من المشروع الأصلي — إذا صممت قالبًا جديدًا
  بأبعاد مختلفة، حدّث هذه القيم لتطابق أبعاد قالبك ومكان الفتحة فيه بالبكسل.

لاحقًا عند إضافة الأفتار والتسجيلات الصوتية (بعدة وضعيات)، يمكن رفعها هنا أيضًا:
- `assets/avatar/` لملفات الأفتار (بحسب كل وضعية)
- `assets/voice/` للتسجيلات الصوتية
