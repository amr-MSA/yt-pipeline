# مقاطع التجميع المحلية

ضع هنا ملفات MP4 التي تستخدمها رسائل `/agg` أو `تجميع`:

- `1.mp4`: المقدمة، ويجب أن تكون أول عنصر في الأمر.
- `2.mp4`: الفاصل الذي يمكن تكراره بين المقاطع.
- `3.mp4`: الخاتمة، ويجب أن تكون آخر عنصر في الأمر.
- يمكن إضافة `4.mp4` وما بعده لاحقاً إذا توسع parser، لكن المسار الحالي يثبت 1 و2 و3.

ملفات MP4 مستثناة من Git عمداً عبر قاعدة `*.mp4` في `.gitignore`. أضف الملفات إلى بيئة GitHub Actions أو غيّر طريقة تخزين الأصول قبل التشغيل الإنتاجي؛ لا تضع ملفات كبيرة أو محمية بحقوق داخل المستودع دون تصريح.

مثال رسالة:

```text
/agg "عنوان التجميعة" 1 https://example.com/a 2 https://example.com/b 2 https://example.com/c 3
```

تعني: `videos/1.mp4` ثم المقطع A ثم `videos/2.mp4` ثم B ثم `videos/2.mp4` ثم C ثم `videos/3.mp4`.
