# المقاطع المحلية الاختيارية للتجميع

أرسل `/agg` أو `تجميع` ثم العنوان والروابط بالترتيب. لا يلزم أي ملف محلي؛ الروابط
يمكن أن تأتي متتالية. إذا أُدرج مؤشر رقمي في الرسالة، يضيف المسار الملف المطابق
في الموضع نفسه، بشرط وجوده:

- `1` أو `1.mp4` ← `videos/1.mp4`
- `2` أو `2.mp4` ← `videos/2.mp4`
- `3` أو `3.mp4` ← `videos/3.mp4`

مثال بروابط فقط:

```text
/agg "عنوان التجميعة" https://example.com/a https://example.com/b
```

مثال مع الفاصل المحلي الاختياري:

```text
/agg "عنوان التجميعة" https://example.com/a 2 https://example.com/b
```

قاعدة `*.mp4` في `.gitignore` تتجاهل ملفات MP4 افتراضياً. `videos/2.mp4` مُضاف
عمداً إلى هذا المستودع العام؛ لا يُضاف ملف محلي آخر إلا بموافقة مناسبة، لأن محتواه
سيكون مرئياً للعامة.
