# 🎬 YouTube Clip Pipeline — نسخة GitHub Actions + Telegram

هذا المشروع نسخة محوّلة من دفتر Colab الأصلي إلى **GitHub Action** يعمل تلقائيًا
حسب جدول زمني، يستقبل روابط يوتيوب عبر **بوتين تلجرام منفصلين**:

- **بوت "لونق" (Long)** → يحمّل الفيديو كاملاً وينشره على قناتك كما هو (فيديو عام).
- **بوت "شورتس" (Shorts)** → يقص أول 60 ثانية (مبدئيًا، للاختبار)، يدمجها داخل قالبك،
  وينشرها كفيديو عام بأبعاد شورتس (1080×1920).

هذه نسخة **مبسطة لاختبار الفكرة**. لاحقًا يمكن إضافة: دمج أفتار،
تسجيلات صوتية، بعدة وضعيات — كل ذلك يُرفع كأصول (assets) داخل الريبو.

بالإضافة، يوجد الآن **خط إنتاج ذكي ثالث ("long-smart")** يُفعَّل بأمر `/long <رابط>`
داخل بوت الشورتس نفسه — راجع القسم 9 أدناه.

## 2) إنشاء البوتين في تلجرام

1. افتح محادثة مع [@BotFather](https://t.me/BotFather) في تلجرام.
2. أرسل `/newbot` واختر اسمًا مثل **"شورتس"** → احفظ التوكن الذي يعطيك إياه.
3. كرر العملية لبوت ثانٍ باسم **"لونق"** → احفظ التوكن الثاني.
4. من هاتفك، ابدأ محادثة مع كل بوت (اضغط Start) حتى يقدر يستقبل رسائلك.

---

## 3) توثيق يوتيوب (مرة واحدة فقط، على جهازك)

GitHub Actions لا يمكنه فتح متصفح لتسجيل الدخول، لذلك نعمل هذه الخطوة **مرة واحدة فقط محليًا**:

1. اذهب إلى [Google Cloud Console](https://console.cloud.google.com/) → أنشئ مشروعًا.
2. فعّل **YouTube Data API v3**.
3. أنشئ بيانات اعتماد OAuth من نوع **Desktop App** ونزّل الملف باسم `client_secret.json`.
4. ضعه بجانب `scripts/generate_token_locally.py` على جهازك.
5. ثبّت المتطلبات محليًا: `pip install -r requirements.txt`
6. شغّل: `python scripts/generate_token_locally.py`
7. سجّل دخول ووافق في المتصفح الذي يفتح تلقائيًا.
8. سيُنشأ ملف `youtube_token.json` — **افتحه وانسخ محتواه بالكامل**.

> ⚠️ لا ترفع `client_secret.json` أو `youtube_token.json` إلى الريبو أبدًا (موجودان في `.gitignore`).

---

## 4) إعداد الأسرار (GitHub Secrets)

في الريبو: **Settings → Secrets and variables → Actions → New repository secret**

| الاسم | القيمة |
|---|---|
| `LONG_BOT_TOKEN` | توكن بوت "لونق" من BotFather |
| `SHORTS_BOT_TOKEN` | توكن بوت "شورتس" من BotFather (يستقبل أيضًا أوامر `/long`) |
| `YOUTUBE_TOKEN_JSON` | محتوى ملف `youtube_token.json` كاملاً (نفس القناة، مشتركة بين كل الخطوط) |
| `YT_COOKIES` | (اختياري) محتوى ملف cookies.txt إذا احتجت تجاوز قيود يوتيوب على بعض الفيديوهات |
| `GEMINI_API_KEY` | مفتاح Gemini API (من Google AI Studio) — مطلوب لخط `/long` الذكي فقط |

## 5) رفع قالب الشورتس

ضع صورة القالب في `assets/template.png` (بنفس الاسم بالضبط) وارفعها (commit) إلى الريبو.

إذا كان قالبك بأبعاد مختلفة عن قالب المشروع الأصلي، عدّل هذه القيم في
`scripts/shorts_pipeline.py`:

```python
TEMPLATE_NATIVE_W, TEMPLATE_NATIVE_H = 941, 1672   # أبعاد صورة القالب نفسها
TEMPLATE_BOX_X, TEMPLATE_BOX_Y = 95, 630           # زاوية منطقة الفيديو داخل القالب
TEMPLATE_BOX_W, TEMPLATE_BOX_H = 750, 435          # عرض/ارتفاع منطقة الفيديو
```

## 6) الجدولة

الأكشن يعمل تلقائيًا 8 مرات يوميًا (بتوقيت السعودية UTC+3):
7ص، 12ظهرًا، 1م، 2م، 5م، 8م، 10م، 12(منتصف الليل).

كل تشغيل يفحص فقط الرسائل **الجديدة** التي وصلت للبوت منذ آخر تشغيل (لا تُعاد معالجة نفس الرابط).

يمكنك أيضًا تشغيل أي سير يدويًا فورًا من تبويب **Actions** في GitHub عبر زر
**"Run workflow"** (بفضل `workflow_dispatch`) بدل انتظار الموعد المجدول.

## 7) طريقة الاستخدام اليومية

1. افتح محادثة بوت "لونق" في تلجرام → أرسل رابط فيديو يوتيوب كامل تريد نشره كما هو.
2. افتح محادثة بوت "شورتس" → أرسل رابط فيديو يوتيوب تريد اقتصاص أول دقيقة منه ونشرها كشورت.
3. انتظر أقرب موعد تشغيل (أو شغّله يدويًا)، وسيصلك رد في تلجرام برابط الفيديو المنشور أو برسالة خطأ إن فشل.

## 9) خط الإنتاج الذكي `/long` (Gemini) — تفصيل كامل

هذا خط **منفصل تمامًا** عن بوت "لونق" العادي وعن سير "شورتس" (القص الثابت 60 ثانية).
يُفعَّل بإرسال أمر داخل **بوت شورتس نفسه**:

```
/long https://youtube.com/watch?v=XXXXXXXX
```

### كيف يعمل

**عند وصول الأمر (فورًا، ضمن أقرب تشغيل لبوت شورتس):**
1. **الطبقة 1** — سحب الملف النصي (الترانسكريبت) مع التوقيت من يوتيوب مباشرة
   (`transcript_utils.py`، عبر ترجمة يوتيوب اليدوية أو التلقائية).
2. **الطبقة 2** — إرسال هذا الترانسكريبت إلى Gemini (`gemini_utils.py`)، الذي يرجع
   **بالضبط 8 مقاطع مقترحة** بصيغة JSON، لكل مقطع: النوع (`long` أو `shorts`)،
   توقيت البداية/النهاية بالثواني، عنوان، ووصف.
3. تُحفظ الـ 8 مقاطع في طابور خاص بهذا الفيديو
   (`state/long_smart_queue/<video_id>.json`) بحالة "بانتظار النشر" لكل منها.
4. يصلك تأكيد في تلجرام أن التحليل نجح، وعدد المقاطع المحفوظة.

**لا يُنشر أي شيء في هذه اللحظة.** النشر يتم فقط عبر التشغيل اليومي التالي.

**كل يوم (تشغيل واحد مجدول، `long_smart_pipeline.yml`، الساعة 8ص بتوقيت السعودية):**
- يمر على كل الطوابير التي فيها مقاطع لم تُنشر بعد.
- يأخذ **مقطعًا واحدًا (الأقدم غير المنشور) من كل طابور نشط** وينشره — أي لو كان
  عندك رابطان قيد المعالجة، يُنشر مقطع من كل واحد منهما في نفس اليوم.
- هذا يستمر تلقائيًا يومًا بعد يوم حتى تُنشر كل الـ 8 مقاطع من كل رابط.
- يصلك تأكيد تلجرام لكل مقطع يُنشر (أو رسالة خطأ إن فشل مقطع معيّن).

### الحد اليومي والعداد الذكي

- الحد الافتراضي: **8 عمليات نشر يوميًا لهذا الخط تحديدًا** (`DAILY_LIMIT` في
  `long_smart_pipeline.py`)، **منفصل تمامًا** عن أي نشاط آخر على القناة (بوت لونق
  الفوري أو بوت شورتس القديم لا يخصمان من هذا العداد ولا يتأثران به).
- العداد محلي (`state/long_smart_quota.json`) ويُصفَّر تلقائيًا كل يوم UTC.
- **كشف ذكي إضافي**: إذا رجع من يوتيوب خطأ كوتا حقيقي (`quotaExceeded` أو ما شابه)،
  يتوقف الخط فورًا عن أي محاولة نشر أخرى في نفس التشغيل، ويُسجَّل ذلك في نفس ملف
  الحالة — حتى لو العداد المحلي لم يصل للحد بعد. هذا يحمي من محاولات رفع فاشلة
  متكررة تهدر وقت التشغيل.

### العنوان والوصف الثابت

ضع أي توقيع/CTA ثابت تريده في:
- `assets/fixed_title.txt` — يُدمَج في **نهاية** عنوان كل مقطع (مثلاً: `| قناتي`).
- `assets/fixed_description.txt` — يُدمَج في **نهاية** وصف كل مقطع (سطرين فراغ ثم
  المحتوى الثابت، مثلاً روابط سوشيال ميديا).

الملفان فارغان افتراضيًا. إذا تركتهما فارغين، يُستخدم عنوان/وصف Gemini كما هو.
إذا تجاوز الدمج حد 100 حرف ليوتيوب للعنوان، يُقصَّر عنوان Gemini تلقائيًا مع
الحفاظ على التوقيع الثابت كاملاً.

### إعداد إضافي مطلوب

- أضف `GEMINI_API_KEY` كـ GitHub Secret (مفتاح من [Google AI Studio](https://aistudio.google.com/apikey)).
- لا حاجة لتوكن يوتيوب إضافي — يُستخدم نفس `YOUTUBE_TOKEN_JSON` الموجود أصلاً.

## 10) قيود النسخة الحالية (ستُطوَّر لاحقًا)

- القص في سير الشورتس **العادي** (بدون `/long`) لا يزال **ثابتًا (أول 60 ثانية)**
  بدون ذكاء اصطناعي — فقط خط `/long` الجديد يستخدم Gemini لاختيار أفضل الأجزاء.
- لا يوجد بعد دمج أفتار أو تسجيلات صوتية — سيُضافان في مرحلة قادمة كأصول في `assets/`.
- النشر دائمًا كـ **فيديو عام (public)** فور المعالجة، بدون جدولة نشر مؤجل.
- حصة يوتيوب اليومية (Quota) محدودة ومشتركة فعليًا بين كل الخطوط عند يوتيوب نفسه
  (رغم أن عدّاد `/long` منفصل منطقيًا في الكود) — إذا نشرت كثيرًا عبر البوتين العاديين
  في نفس اليوم، قد يتأثر رفع خط `/long` أيضًا ويظهر ذلك كخطأ كوتا من يوتيوب.
- خط `/long` يعتمد على وجود ترجمة (يدوية أو تلقائية) على الفيديو المصدر في يوتيوب؛
  إن لم توجد، تفشل المعالجة برسالة واضحة في تلجرام.
