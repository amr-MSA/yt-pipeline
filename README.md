# قناة Long — YouTube Pipeline

هذا المستودع مخصص لقناة المحتوى الحالية وبوت `Long` فقط.

## المسار الحالي

1. يرسل المستخدم رابطًا إلى بوت Long.
2. ينزّل البوت الفيديو كاملًا عبر `yt-dlp`.
3. يرفع الملف الناتج كما هو، دون قالب أو قص أو إعادة تحجيم أو خلفية مموهة.
4. يرفعه Public إلى قناة YouTube الحالية.
5. يحفظ الحالة ويحذف رسالة Telegram بعد تأكيد النشر.

## التشغيل

الـWorkflow الفعال الوحيد هو `.github/workflows/long_pipeline.yml`. يعمل كل ساعة أو يدويًا.

الأسرار المطلوبة في هذا المستودع:

- `LONG_BOT_TOKEN`
- `YOUTUBE_TOKEN_JSON` للقناة الحالية
- `YT_COOKIES` عند الحاجة للتنزيل

## الفصل

تم نقل Shorts وLong-Smart إلى المستودع الخاص بالقناة الثانية: `yt-pipeline-smart`.
النسخ القديمة محفوظة تحت `.github/workflows-disabled/` و`archive/` لأغراض الرجوع فقط، ولا تعمل GitHub Actions من هناك.

## الحالة

يُستخدم فقط ما يتعلق ببوت Long داخل `state/`: inbox وoffset وسجل النشر والتأكيدات.
لا تُنقل حالة القناة الحالية أو أسرارها إلى المستودع الثاني.
